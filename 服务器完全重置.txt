========================================
服务器完全重置流程
========================================

在服务器上执行以下命令（已连接到服务器）：

# 1. 停止所有应用进程
pkill -9 -f "python.*app.py"
sleep 2
ps aux | grep "python.*app.py" | grep -v grep

# 2. 进入项目目录
cd /www/wwwroot/FCN_SweetSeek

# 3. 备份重要数据（可选，以防万一）
mkdir -p /tmp/sweetseek_backup_$(date +%Y%m%d_%H%M%S)
cp -r chroma_db /tmp/sweetseek_backup_$(date +%Y%m%d_%H%M%S)/ 2>/dev/null || echo "无需备份"

# 4. 删除向量数据库（这是关键！）
rm -rf chroma_db
echo "✅ 已删除向量数据库"

# 5. 查看当前Git状态
git status

# 6. 重置所有本地修改（保留未跟踪的文件）
git reset --hard HEAD

# 7. 拉取最新代码
git pull origin RenJiaqi

# 8. 验证代码已更新
git log -1 --oneline

# 9. 检查虚拟环境
ls -la venv/bin/python
/www/wwwroot/FCN_SweetSeek/venv/bin/python --version

# 10. 启动应用（会自动重建索引）
nohup /www/wwwroot/FCN_SweetSeek/venv/bin/python app.py > logs/app.log 2>&1 &

# 11. 等待启动（重建索引需要时间，大约2-5分钟）
echo "等待应用启动和索引重建（这需要几分钟）..."
sleep 10

# 12. 监控启动日志
tail -f logs/app.log

# 按 Ctrl+C 停止查看日志

# 13. 验证服务状态
ps aux | grep "python.*app.py" | grep -v grep
netstat -tlnp | grep 5001

========================================
预期输出
========================================

启动日志应该包含：
- [系统] 初始化RAG系统...
- 📚 将从 ./sweet_related_paper 读取 XXX 个文档
- 📖 读取到 XXX 个文档，开始构建向量索引...
- 📝 开始提取PDF元数据...
- ✅ 成功提取 XX 个PDF文件的元数据
- ✅ 索引构建完成并存储到Chroma
- [成功] 系统初始化完成
- [统计] 文档数: XXXX
- ✅ 服务器启动成功

如果看到这些信息，说明索引重建成功！

========================================
故障排查
========================================

如果启动失败，查看完整日志：
tail -100 logs/app.log

如果索引构建卡住，检查磁盘空间：
df -h

如果进程启动但立即退出，手动启动查看错误：
/www/wwwroot/FCN_SweetSeek/venv/bin/python app.py
