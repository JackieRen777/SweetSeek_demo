# 问题解决报告

## 错误信息
```
[System Error: shapes (512,) and (768,) not aligned: 512 (dim 0) != 768 (dim 0)]
```

## 问题分析

### 根本原因
Dual-Protein Q&A系统的索引使用768维零向量构建，但查询时使用512维的真实嵌入模型（bge-small-zh-v1.5），导致维度不匹配。

### 为什么会出现这个问题？
1. **历史遗留**：旧代码使用768维的零向量占位符构建索引
2. **模型更新**：修复后使用512维的bge-small-zh-v1.5真实模型
3. **索引未同步**：Sweet Q&A已重建，但Dual-Protein未重建

## 解决方案

### 1. 重建Dual-Protein索引
使用与Sweet Q&A相同的512维嵌入模型重建索引：

```python
from persistent_storage import PersistentRAGSystem

dual_protein_rag = PersistentRAGSystem(
    data_dir='./Dual_Protein_related_paper/papers',
    persist_dir='./storage_dual_protein'
)

success = dual_protein_rag.rebuild_index()
```

### 2. 验证结果
- ✅ 索引重建成功：4588个文档块（之前2517个）
- ✅ 文件覆盖：97个PDF全部索引
- ✅ 检索测试：Score正常（0.67-0.71）
- ✅ 维度统一：512维

### 3. 重启服务
重启后端服务以加载新索引，并初始化Dual-Protein系统。
