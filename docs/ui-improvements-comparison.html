改进 #3: Linked Records 统一空状态

避免重复 3 次"无数据"提示

🔴 P0 - 高优先级
影响分子 ~40%
空间节省 66%
改进前

三个独立空状态

No food sources recorded for this compound.

No receptor binding data available.

No regulatory information recorded.

  • 三个模块都为空时，占用大量垂直空间
  • 重复说"无数据"，信息冗余
  • 用户需要滚动浏览空白内容
改进后

统一空状态 + 条件渲染

No linked records available

This compound has no food source, receptor binding, or regulatory data currently recorded.

  • 三个空模块合并为一个统一提示
  • 节省 66% 空间
  • 只显示有数据的模块
  • 所有为空时显示一次综合提示
// DatabaseInterface.tsx 修改位置：第 625-627 行 const hasAnyLinkedData = hasFoodSources || hasReceptors || hasRegulatory; {!hasAnyLinkedData ? ( <div className="sdb-empty-state"> <h3>No linked records available</h3> <p>This compound has no food source, receptor binding, or regulatory data currently recorded.</p> </div> ) : ( <> {hasFoodSources && <FoodSourcesTable data={foodSources} />} {hasReceptors && <ReceptorBindingTable data={receptorBindings} />} {hasRegulatory && <RegulatoryInfoTable data={regulatoryInfo} />} </> )}
用户体验提升 用户看到的是"确认的事实"而非"确认的缺失"，专业感显著提升
