## 分类结论

- 核心源码：前端九个功能、Flask API、服务层、FAISS 存储、ML 和 MD Builder，全部保留。
- 不可再生资产：统一论文库和元数据，全部保留且排除 Git/部署同步。
- 可再生资产：FAISS 索引、前端依赖和构建、虚拟环境、缓存与日志，不进入 Git。
- 唯一运维入口：新 ECS 初始化和一键发布、本地重启、索引维护、清理验证。

## 已删除或停止跟踪

- 含明文口令的远程诊断/覆盖脚本和私有环境文件。
- 两代旧服务器部署、推送、重启、回滚和代理脚本。

代码恢复依赖本阶段的独立 Git 提交。Git 历史仍包含旧大文件和已轮换凭据，历史重写不属于本阶段。

- 前端 Three.js 主 chunk 仍较大，后续做 bundle 分析，不在本阶段改变功能加载逻辑。
