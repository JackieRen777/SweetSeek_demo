========================================
服务器更新命令（复制粘贴执行）
========================================

1. 登录阿里云VNC
   https://ecs.console.aliyun.com

2. 在VNC终端中执行以下命令：

# 进入项目目录
cd /www/wwwroot/FCN_SweetSeek

# 拉取最新代码
git pull origin RenJiaqi

# 重启服务
./restart-server.sh

# 等待5秒
sleep 5

# 验证健康状态
curl http://localhost:5001/api/health

# 查看日志（按Ctrl+C退出）
tail -f logs/sweetseek.log

========================================

3. 在本地电脑验证外部访问：

./test_external_access.sh

或访问浏览器：
http://8.137.32.247:5001

========================================
预期结果：
- git pull 显示更新的文件
- restart-server.sh 显示服务重启成功
- health 返回 {"status": "healthy"}
- 外部可以正常访问
========================================
